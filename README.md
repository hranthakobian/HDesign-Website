# Custom QR Designer

Next.js + SASS website for generating custom QR-style artwork with:

- vertical line-based modules
- adjustable line thickness
- configurable corner marker shapes
- optional centered logo overlay

## Setup

Install dependencies and run the app:

```bash
npm install
npm run dev
```

## Notes

The workspace has been scaffolded for a custom QR generator UI. Once dependencies are installed, the generator can be extended with your preferred QR rendering logic and logo assets.
